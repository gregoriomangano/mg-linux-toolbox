# Strumenti per la build AppImage

Questa directory non contiene binari precompilati.

Per una futura build locale, ottenere `appimagetool.AppImage` dalla fonte ufficiale AppImage, verificarne versione, licenza e checksum, quindi collocarlo qui con permesso di esecuzione.

La nuova AppImage ufficiale di M.G Linux Toolbox non è stata ancora costruita.
