# Disclaimer

M.G Linux Toolbox può modificare impostazioni del sistema. Le modifiche
temporanee sono consigliate durante le prime prove. Prima delle
modifiche permanenti è consigliabile disporre di un backup. Il software
viene fornito così com'è, senza garanzia di compatibilità con ogni
distribuzione, kernel o configurazione hardware, nei limiti consentiti
dalla legge.

Il programma prova a conservare e ripristinare i valori precedenti, ma
nessun software può garantire l'assenza assoluta di problemi.

## Privacy

- Nessuna telemetria.
- Nessun account richiesto.
- Nessun dato inviato automaticamente.
- Il controllo aggiornamenti contatta soltanto la sorgente delle
  release (quando configurata).
- Il rapporto tecnico diagnostico viene creato localmente e condiviso
  soltanto se l'utente decide di farlo.
