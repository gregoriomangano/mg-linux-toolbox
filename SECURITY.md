# Sicurezza

## Segnalare un problema

Non pubblicare dettagli che permettano di sfruttare un problema prima che sia stato valutato.

Invia una descrizione minima a `contattogregorio82@gmail.com` con oggetto `Sicurezza M.G Linux Toolbox`. Indica:

- componente interessato;
- comportamento osservato;
- distribuzione e kernel;
- passaggi minimi per riprodurre il problema;
- possibile impatto.

Rimuovi password, chiavi, nomi utente, hostname, indirizzi di rete, percorsi personali, log completi e database reali.

## Ambito

Sono particolarmente importanti le segnalazioni relative a:

- esecuzione di comandi con privilegi;
- scrittura di configurazioni permanenti;
- download e verifica degli aggiornamenti;
- ripristino dei valori precedenti;
- gestione di percorsi e file temporanei.

## Uso prudente

Verifica sempre l'azione mostrata prima di concedere privilegi. Prova temporaneamente una modifica quando possibile e conserva un punto di ripristino. Non usare una funzione che il programma indica come non supportata dal sistema.
